**Goal:** Ship the authenticated shared NPR expense app on a public ChatGPT Site and in a public GitHub repository.

**Architecture:** Supported Vinext starter, React client using REST, Worker API, D1 database. Shared domain types and pure monetary/review calculations are independent of the UI and persistence.

**Tech Stack:** TypeScript, React, Vinext, Cloudflare Workers/D1, Drizzle migrations, native Web Crypto, native Node test runner.

**Spec:** `outputs/kittakat-design.md` in the parent task; copied into repository `docs/superpowers/specs/2026-11-01-kittakat-design.md`.

## Global Constraints
- Exact Nepali name `कित्ताकाट` and logo `क`; public GitHub `imadarshk/kittakat`.
- Password registration without email verification; ChatGPT auth disabled by default in source, enabled only on Sites runtime.
- NPR integer-paisa calculations, four split modes, explicit participants, immutable revisions, per-person debt and immediate disputed/pending balances.
- Notifications main navigation; reports/create/join/invites/support message in Settings.
- Exact support sentence from the spec; no production test records or credentials in source.

## Review Focus
- Cross-space IDs and former participants: reject unauthorized reads/writes, permit reviewing removal revisions.
- Fractional costs and rounding: no lost paisa, invalid totals rejected.
- Concurrent corrections and stale accept/dispute actions: no lost revisions or acceptance of obsolete data.
- Multiple disputes: correction alone does not close them; each disputer must accept a later revision.
- Authentication mode boundaries, cookie/CSRF/rate limits and CSV formula injection.

## File and API contracts
`lib/types.ts` owns User, Space, Member, ExpenseInput, RepaymentInput, Entry, Review, Dispute, Notice, Bootstrap. REST JSON errors are `{error:string}`. `Bootstrap` is `{user:User|null,chatgptEnabled:boolean,spaces:Space[],activeSpace:Space|null,members:Member[],entries:Entry[],notices:Notice[],reviews:Review[],disputes:Dispute[]}`. Space includes `id,name,ownerId,code,currency:'NPR',createdAt`. Entry includes `id,spaceId,creatorId,revision,createdAt,payload:ExpensePayload|RepaymentPayload,history:Revision[]`; payload expense includes integer `amountCents`, `paidById`, `participantIds`, `splitMethod`, `splitValues`, computed `portions:Record<userId,integer>`, title/category/date; repayment includes amountCents/date/fromId/toId/title. Revision includes revision,payload,reason,actorId,createdAt. Review includes entryId,revision,userId,status,reason. Dispute includes id,entryId,userId,openedRevision,reason,resolvedRevision|null. Notice includes id,spaceId,entryId,revision,recipientId,actorId,type,reason,createdAt,readAt|null.

Endpoints: GET `/api/bootstrap?spaceId=...`; POST `/api/auth/register` (username,password,displayName), `/api/auth/login`, `/api/auth/logout`; POST `/api/spaces` (name), `/api/spaces/join` (code), `/api/spaces/:id/code` (owner rotation); POST `/api/spaces/:id/entries` (input), `/api/spaces/:id/entries/:entryId/revise` (input plus expectedRevision,reason), `/api/spaces/:id/entries/:entryId/review` (revision,action,reason); POST `/api/spaces/:id/notifications/read` (ids optional); GET `/api/spaces/:id/export?format=xlsx|csv&type=expenses|splits|repayments|balances|history&from=&to=`. Successful mutations return an object with `id` or `{ok:true}`; client refreshes Bootstrap. Cookies carry authentication. ChatGPT sign-in uses normal top-level anchor `/signin-with-chatgpt?return_to=/`.
